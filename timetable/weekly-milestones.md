# Weekly Milestones

| 周 | 主题 | 必须完成 | 可选增强 |
| --- | --- | --- | --- |
| Week 1 | GitHub Actions 入门 | 一个可以在 PR 触发的 CI workflow | 添加缓存、矩阵构建 |
| Week 2 | CI 工程化 | lint/test/build 分阶段执行 | 添加 artifact 和测试报告 |
| Week 3 | Docker 基础 | 为示例项目编写 Dockerfile | 多阶段构建、镜像瘦身 |
| Week 4 | GHCR 镜像发布 | Actions 自动构建并推送镜像 | Trivy 镜像扫描 |
| Week 5 | CD 与 Environments | dev/prod 环境、审批、secrets | 部署到测试服务器或模拟部署 |
| Week 6 | 安全与质量 | Dependabot、CodeQL、secret 管理 | SBOM、Gitleaks、权限最小化 |
| Week 7 | K8s 基础 | 写出 Deployment/Service/Ingress | 使用 kind/minikube 本地验证 |
| Week 8 | ACK 与 GitOps 预备 | ACK 架构设计、Helm/Kustomize 初步 | Argo CD 方案设计 |
| Week 9 | Agent 基础 | CI failure analyzer 原型 | GitHub API 拉取 workflow run |
| Week 10 | Agent 集成 | PR summary/release note agent | 自动评论 PR |
| Week 11 | 收尾复盘 | 端到端演示、最终 README、路线复盘 | 下一阶段学习计划 |

## 每周验收方式

每周至少完成：

- 1 篇学习笔记。
- 1 次可运行实验。
- 1 个 GitHub commit。
- 1 份周复盘。

每两周至少完成：

- 1 个可展示的小项目产出。
- 1 次从失败到修复的完整记录。
